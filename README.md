# Live Translate Hub

Készíts egy egyszerű, de design web oldalt, mely az alábbiakat csinálja:
- A user kiválasztja a beviteli és az output nyelvet
- A user folyamatosan beszél a lap top mikrofonjába
- A a képernyőn folyamatosan, szinkronfordításban kiíródik az output nyelven a kimondott szöveg, 

Értsd meg az igényt, keresd meg a legjobb megoldást arra, hogy folyamatos, valós idejű legyen a fordítás (mondatokat össze kell talán várni - gondolom AI alapú) részletesen tervezd meg a web oldalt, és lépésről lépésre írd meg a specifikációt majd gondosan, ügyelve a legapróbb réslzetekre fejleszd le a web oldalt.Ha egy ponton bizonytalan vagy a megoldásban, gondol át újra és keress egy biztosan működő megoldást.

Ellenőrzid hogy minden fukció múködjön.
